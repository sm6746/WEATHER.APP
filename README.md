# 🌤️ Weather App

A responsive web application built with HTML, CSS, and JavaScript that displays real-time weather information using the [OpenWeatherMap API](https://openweathermap.org/api). The app features dynamic background updates tailored to each searched city!

---

## ✨ Features

* **Real-Time Weather Data:** Displays temperature, atmospheric details, and weather conditions.
* **Dynamic Backgrounds:** Automatically updates the background image dynamically based on the city searched.
* **Global City Search:** Easily search weather conditions for cities around the world.
* **Pure Web Tech:** Lightweight and fast, built using vanilla HTML5, CSS3, and JavaScript (ES6).

---

## 🛠️ Tech Stack

* **HTML5** – Web page layout and structure.
* **CSS3** – Styling and custom background handling.
* **JavaScript (ES6)** – Fetch API integration, DOM manipulation, and dynamic updates.
* **API** – [OpenWeatherMap API](https://openweathermap.org/)

---

## 🚀 Getting Started

Follow these steps to run the application on your local machine:

### Prerequisites

You need a free API key from OpenWeatherMap to fetch weather data:
1. Sign up for a free account on [OpenWeatherMap](https://openweathermap.org/).
2. Navigate to your account dashboard and go to **API Keys**.
3. Copy your API key.



 **Launch the App:**
* Open `index.html` directly in any browser.
